# Changelog v1.0.0 (MVP Release)

## Visão Geral
O **App Presença** foi construído do zero com o objetivo de ser uma plataforma enxuta, responsiva e escalável focada estritamente em registrar presenças escolares/acadêmicas de forma rápida usando Códigos QR.

## 🏗️ Arquitetura e Stack
- **Framework Base:** Next.js 14+ (App Router)
- **Banco de Dados:** Prisma ORM migrado do SQLite (dev) para **PostgreSQL (Supabase)**.
- **Autenticação:** NextAuth.js v5 (JWT com controle de sessões e Roles).
- **Segurança Multi-Empresa:** Arquitetura *Multi-Tenant* (Todas as tabelas possuem `tenantId` garantindo isolamento total de dados entre escolas).

## ✨ Funcionalidades Principais (Features)

### 👨‍💻 Painel Administrador
- **Dashboard de Métricas:** Contadores rápidos de Cursos, Alunos e Aulas (Sessões).
- **Gestão de Alunos (CRUD):** Criação de perfis e geração automática de QR Codes únicos. Opção de deleção em cascata (limpando o histórico do aluno automaticamente).
- **Gestão de Turmas/Cursos (CRUD):** Criação e deleção de cursos.
- **Gerenciador de Matrículas:** Permite ao Admin vincular/matricular alunos nas turmas com um clique (`useTransition` + Server Actions para atualizações em tempo real).

### 📱 Aplicativo do Colaborador (Scanner QR)
- **Seleção de Turma:** O colaborador escolhe a Turma (Course) antes de iniciar a chamada.
- **Criação de Sessão Automática (Aula):** O sistema detecta se há uma aula para o dia corrente. Caso não, ele instancia uma Sessão no banco.
- **Leitura Contínua de QR:** Integração com `html5-qrcode` abrindo a câmera e computando presenças sem precisar recarregar a tela.
- **Feedback Visual Nativo:** Uso de notificações *Toasts* (`sonner`) em vez de alertas de navegador feios, dando aspecto mobile nativo.

### 🎨 Design System e UI/UX (Mobile-First)
- **Tema:** Dark/Cyber-Green Neon (Inspirado no protótipo CodeQuery SerQ).
- **Glassmorphism:** Uso intensivo de caixas translúcidas com `backdrop-filter: blur`.
- **Navbar Flutuante:** Navegação inferior no Admin estilo pílula arredondada com ícones (`lucide-react`) e indicativos de aba ativa com brilho neon.
- **Responsividade Total:** 
  - Tabelas envoltas em contêineres de rolagem horizontal (Swipe to Scroll).
  - Headers Flexíveis para evitar quebra de layout no Mobile.
  - Maximização da tela da câmera.

### ⚙️ Integração Nativa (Android)
- **Capacitor.js:** Toda a plataforma web foi encapsulada para o Android Studio, gerando a pasta `/android`. O `.apk` apontará para a URL de produção na Vercel carregando o aplicativo inteiro num ambiente mobile nativo.

## 🗄️ Estrutura do Banco de Dados Final
- `Tenant`: Escolas/Empresas.
- `User`: Admin, Colaborador e Estudantes (com vínculos ao Tenant).
- `Course`: Turmas.
- `Enrollment`: Tabela pivô vinculando Aluno a Curso.
- `Session`: A aula de um dia específico.
- `Attendance`: O registro final de que o Aluno X compareceu à Sessão Y. (Proteção contra batidas duplicadas no mesmo dia).

## 🚀 Status da Implantação e Migração (Vercel & Supabase)
- **Supabase Auth:** Remoção total do `NextAuth` e `nodemailer`. Implementação nativa do `@supabase/ssr` para gerenciar login, cadastro e sessões via Cookies.
- **Custom SMTP (Google):** Configurado SMTP customizado no Supabase (`smtp.gmail.com`) usando *App Passwords*, burlando limites do plano grátis (capacidade de 500 e-mails/dia).
- **Template de E-mail:** Design "Cyber-Green" premium criado (`novo_template_email.html`) para disparar os tokens de OTP de 6 dígitos.
- **Conexão IPv4 (Supavisor):** Configurada a conexão Prisma -> Supabase usando o *Connection Pooler* (porta 6543) com `?pgbouncer=true` para resolver a incompatibilidade de rede IPv4 da Vercel.
- **UX Improvements:** Adicionado botão de "olhinho" para ver/esconder senhas nos formulários de cadastro e login usando `lucide-react`.
- **Limpeza de Código:** Desinstalados pacotes obsoletos e limpas variáveis vazias no `.env.local` e rotas de API antigas.
- **Tratamento de Erros:** Engatilhado um bloco `try/catch` explícito na Server Action de verificação de e-mail para capturar falhas reais do Prisma no lugar do genérico "React Error #441".
